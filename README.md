# Pravinder Singh — Personal Portfolio

A responsive, single-page personal portfolio website built with plain HTML, CSS, and JavaScript. No framework, build step, or paid service is required.

## Preview locally
Open `index.html` in a browser.

## Before publishing
1. Open `index.html` in a text editor.
2. Find `your.email@example.com` and replace it with your professional email address in the contact link and JavaScript.
3. Optionally add your LinkedIn profile URL and links to completed projects.
4. Check that all details are accurate before making the site public.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account at https://github.com/.
2. Create a new **public** repository named `pravinder-portfolio` (or another name you prefer).
3. Upload `index.html` to the repository's root. You may also upload this README.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose branch `main` and folder `/(root)`, then click **Save**.
7. Wait a few minutes. GitHub Pages will show your website URL in the Pages settings. It usually looks like `https://YOUR-USERNAME.github.io/pravinder-portfolio/`.

GitHub's interface may change slightly. A custom domain is optional and normally costs money; the GitHub Pages address is free.

## Notes
- This website uses no external images, fonts, analytics, or paid APIs.
- Project cards are labelled as ideas, not as completed work. Replace them with genuine project details and findings as you build your portfolio.
- Do not publish private information such as your home address or personal identification numbers.
